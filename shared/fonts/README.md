# Шрифти

Inter та Inter Tight, підмножини latin / latin-ext / cyrillic / cyrillic-ext.
Автор — Rasmus Andersson. Ліцензія SIL Open Font License 1.1:
<https://github.com/rsms/inter/blob/master/LICENSE.txt>

Файли лежать у репозиторії свідомо. Під час рендеру Chrome не має ходити в мережу:
запит до Google Fonts підвішував headless-збірку на хвилини.

Оновити (звантажує ті самі файли з Google Fonts і перезаписує @font-face у theme.css):
дивись історію комітів — скрипт разовий, у репозиторії не зберігається.
